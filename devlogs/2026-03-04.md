# Devlog — 2026-03-04

## 今日完成

### Bug Fix: PDF 下载功能修复
- **问题**：论文搜索后点击"下载 PDF"对非 arXiv 来源（PubMed、CrossRef、bioRxiv 等）始终失败
- **根因**：`_try_download_pdf()` 只做简单 `httpx.get(url)`，对落地页 URL 获取到 HTML 而非 PDF，返回 None。项目已有完善的 `PaperDownloader` 类但未被使用
- **修复**：
  - `_try_download_pdf` 改用 `PaperDownloader`（arXiv + Unpaywall DOI→OA + 直链三级策略）
  - `DownloadPdfRequest` 新增 `doi` 字段
  - 前端 `downloadPdf()` 传入 `result.doi`
  - 同步修复 `save_to_kb` 和 `download_and_analyze` 两个端点的调用
- **影响文件**：`src/api/routes/paper_search.py`、`src/api/schemas.py`、`web/src/api/paperSearch.ts`、`web/src/pages/PaperSearchPage.tsx`
