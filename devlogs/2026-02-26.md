## 技术细节

### AnalysisContext 全局状态方案

选择 React Context 而非 Redux/Zustand 的原因：
1. 状态结构简单（进度百分比、步骤名、文件名、是否进行中）
2. 只需跨页面共享，不需要持久化到 localStorage
3. 已有项目无状态管理库依赖，引入新库成本不合理
4. Context + useReducer 足够满足需求

组件层级：
```
App
├── AnalysisProvider  ← 全局状态
│   ├── GlobalProgressBanner  ← 顶部进度条（仅分析中可见）
│   ├── Sidebar
│   └── Routes
│       ├── AnalyzePage  ← 写入分析状态
│       ├── DashboardPage
│       └── ...
```
