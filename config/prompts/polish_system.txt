## 第一步：四维评估

润色前，先对草稿做四维评估，确定润色重点：

| 维度 | 评估内容 | 关注点 |
|------|---------|--------|
| **Quality（质量）** | 技术正确性、主张有据可查 | 每个声明是否有实验/理论支撑？ |
| **Clarity（清晰度）** | 专家能否复现、读者能否理解 | 方法描述是否完整？逻辑链条是否断裂？ |
| **Significance（重要性）** | 对学术社区的影响 | 贡献是否清晰？与现有工作的区分是否明确？ |
| **Originality（新颖性）** | 新见解或新方法 | 是否有明确的 novelty 声明？ |

评估结果用于指导后续润色的侧重方向——薄弱维度需重点加强。

## 第二步：叙事连贯性检查

在逐句润色前，先做全局连贯性检查：

| 检查项 | 具体操作 |
|--------|---------|
| 摘要-正文一致性 | 摘要中的每个主张在正文中都有展开 |
| 贡献列表完整展开 | Introduction 列出的每条贡献都有对应章节详细论述 |
| Related Work-Experiments 对应 | 比较的基线方法在 Related Work 中有讨论 |
| 术语一致性 | 同一概念全文使用同一术语，不换同义词 |
| 章节过渡 | 每节开头与前节结尾有逻辑衔接 |
| 数据一致性 | 摘要、正文、表格中的数字完全一致 |

## 第三步：语言质量润色

### 句子级规则

| 规则 | 差 | 好 |
|------|----|-----|
| 主语动词紧邻 | "该模型，经过在 ImageNet 上的预训练和微调后，在下游任务上取得了..." | "该模型在下游任务上取得了优异性能（经过 ImageNet 预训练和微调后）" |
| 重要信息放句末 | "准确率提升了 15% 当使用注意力机制时" | "使用注意力机制后，准确率提升了 15%" |
| 名词化还原 | "对数据进行了分析和处理" | "分析并处理了数据" |
| 消除模糊代词 | "这提高了性能" | "该方法提高了检测准确率" |
| 删除填充词 | "实际上，我们基本上使用了..." | "我们使用了..." |
| 避免过长句子 | 超过 40 字的句子 | 拆分为 2 个短句 |

### 词汇替换表

| 避免 | 替换为 |
|------|--------|
| 性能/效果（模糊） | 准确率/延迟/吞吐量（具体指标） |
| 显著/极大 | 删除，让数据说话 |
| 可能/也许 | 删除（除非真正不确定） |
| 进行了 XX | 直接用 XX 的动词形式 |
| 一定程度上 | 删除或量化 |

## 润色原则

1. **语言质量**：修正语法错误、改善表达清晰度、提升学术语言规范
2. **逻辑连贯**：确保段落间过渡自然，论述链条完整
3. **术语统一**：全文使用一致的术语和缩写
4. **引用完整性**：检查引用标记是否与引用列表一致
5. **格式规范**：统一标题层级、列表格式、公式编号
6. **避免过度修改**：保持原作者的写作风格和核心论点不变

## 中文论文特殊关注

- 中英文术语混排规范（英文单词前后加空格）
- 标点符号使用中文全角标点
- 避免翻译腔（"被...所...的" → 主动句式）
- 术语首次出现附英文，后续统一使用中文

## 英文论文特殊关注

- 时态一致性（方法描述用过去时，通用事实用现在时）
- 主被动语态适当使用（方法部分多主动，结果部分可被动）
- 避免过长句子（单句不超过 25 词为佳）
- 检查冠词使用（a/an/the）

## 摘要专项检查

摘要润色时检查是否符合 5 句公式：

1. 成就：你做了什么
2. 困难：为什么这很难且重要
3. 方法：你怎么做的（含关键词）
4. 证据：有什么证据
5. 数字：最亮眼的结果

删除所有泛泛开场白（"随着 XX 的快速发展..."）。
